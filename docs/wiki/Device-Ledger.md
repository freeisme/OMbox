# 机房设备台账（网络设备 / 服务器）

页面：`/datacenter-devices`。只维护机房里的网络设备与服务器，办公终端和 IT 物资在各自模块管理。

## 字段

设备编号（唯一）、设备名称、型号库关联、品牌型号、设备类型、占用高度（U）、SN/ST、
固资编码、使用人/责任人、状态、备注。

## 状态机

| 状态 | 含义 | 谁能改 |
| --- | --- | --- |
| 未上架 `stock` | 在库房或待上架，可以被上架 | 台账页 / 上架下架自动 |
| 上架 `installed` | 已经放进某个机柜 | 只能由机柜视图的上架操作写入 |
| 维修 `repair` | 仍在机柜里占位，但标记为故障维修 | 台账页 |
| 报废 `scrapped` | 不再使用，不允许再上架 | 台账页 |

规则：

1. 台账页手工选择「上架」会被拒绝，提示由上架操作设置；
2. 已上架设备要改回「未上架」，必须先在机柜视图下架；
3. 设备仍在机柜里时不能在台账里删除；
4. 只有「未上架」设备会出现在机柜视图的待上架列表里；
5. 上架同步写入所在机房与机柜，下架清空位置并回到未上架。

## 上传 Excel 导入

支持 `.xlsx` / `.xlsm` / `.csv`（第一个工作表，上限 8MB、1000 行）。
表头必须包含**设备编号**与**设备名称**，其余列按名称自动识别
（大小写、空格、下划线、连字符忽略）：

设备编号、设备名称、品牌型号、设备类型、占用高度、SN/ST、固资编码、使用人、
用途、远程访问地址、CPU、内存、硬盘、状态、备注。

* **设备类型不限于预设枚举**：服务器、网络设备、交换机、配线架、UPS、存储、KVM、散热、理线等
  常见写法会自动归一化成标准值，其余（如「光模块」「KVM 延长器」）按填写的原文保存，最多 64 个字符；
* 占用高度允许 `2U`、`2`、`2.0`，范围 1-50U；
* 状态只接受「未上架 / 维修 / 报废」，写「上架」会被拒绝；
* 先预览后导入：显示识别到的列、总行数、将新增/更新/跳过的数量与逐行错误；
* 重复设备（按设备编号）可选「跳过」或「更新」；
* 单行出错只影响该行，其余照常导入，错误带 Excel 行号与原因；
* 台账页「下载模板」生成带表头与示例行的 CSV。

接口：`POST /api/datacenter-devices/import`，请求体
`{"fileName","contentBase64","dryRun","mode"}`。
