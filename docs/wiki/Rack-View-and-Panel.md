# 机柜视图与设备面板

## 机柜视图 `/rack-layout`

把机房设备台账里的设备放到机柜的具体 U 位。位置模型：起始 U 位（从下往上编号）、
占用高度（整数 U）、安装面（前面板 / 后面板 / 整机深度）。

**位置规则**

1. 前后面板各自成层，可以同位共存；整机深度独占该 U 位；
2. 越界、重叠、同一台设备重复上架都会被拒绝；
3. 占用统计按物理 U 行去重，前后面板重叠不重复计数；
4. 上架与下架都会同步设备状态（未上架 ↔ 上架）与所在位置。

**操作**

* 拖动设备换 U 位（吸附整数 U，冲突时提示占用者并回退）；
* 右侧「未上架设备」点选后点空位上架；属性面板可改名称、U 位、高度、类型、安装面；
* 「单柜 / 并排」切换：并排模式把同一机房的机柜横向排开、共用 U 行高、只读展示，
  点任意设备回到单柜视图编辑；
* 导出设备清单（CSV）、打印机柜图、按当前机柜发起巡检。

## 设备面板 `/device-panel`

按型号渲染设备面板：有面板图时用图片作底、端口热点叠加；没有图则按端口模板自绘。
端口按已连接 / 空闲 / 断开着色，点两个端口即可建立链路。

**端口与链路**

* 端口属于已上架设备，支持端口名、类型、类别（电口/光口/电源/Console）、行列位置、状态；
* 按型号模板生成端口是快照，之后可单独增删改；
* **一个端口只能有一条活动链路**，不允许自己连自己，跨机柜/跨站点允许；
* 删除端口会连带删除它的链路，并写入审计。

**面板图片**

「型号与面板图」对话框可新建/编辑型号（厂商、型号、编码、U 高、类别、端口列表每行
`端口名,类型`），并上传正面/背面面板图（PNG / JPEG / WebP，单张 2MB 以内）。
文件存放在 `web/assets/device-images/<厂商>/<型号>.<面>.<扩展名>`，
顶栏可切换「显示面板图」，图片加载失败会自动回退到自绘。
