# 会议室

页面：`/meeting-rooms`（侧边栏「巡检管理 → 会议室」）。

会议室是**独立的巡检对象**（`asset_site.site_type = meeting_room`），不挂机柜，
但它和机房、弱电间一样可以被巡检，也有自己的设备清单。

## 维护会议室

* 新增 / 编辑 / 删除会议室：填**名称**（必填）与**位置**、备注，编码留空会按规则自动生成；
* 列表直接显示每个会议室的**设备数**，点「设备（N）」打开设备清单与登记表单；
* 删除会议室前要先把里面的设备清掉；会议室被巡检任务引用过时，历史巡检表仍保留当时的快照。

## 会议室内设备

会议室设备有两种登记方式（表 `site_device`）：

1. **从 IT 物资分配**：选仓库 + 型号 + 数量，按数量扣减该仓库与型号的库存，并写库存流水；
2. **自定义登记**：直接填名称、型号、数量与备注，用于目录里没有的物件。

设备登记后可以改数量或删除；删除只影响会议室清单，不回写 IT 物资库存
（要退库请到「IT 物资」做归还 / 调整）。

## 会议室巡检

* 系统自带**「会议室巡检」模板**（33 项），类别覆盖环境、显示设备、连接功能、音频设备、
  视频设备等；模板可以改、可以删，也可以自己新建，并在模板上选择适用对象（机房 / 弱电间 /
  会议室 / 通用）；
* 在「巡检中心」点「开始巡检」时可以**多选对象**：每个会议室生成一张巡检表，
  同一批共用一个批次号，导出时可以按批次把所有对象**横向**排在一张表里；
* 现场也可以用「下载模板 → 填表 → 导入巡检表」的方式补录，「巡检对象」一列写会议室名称。
