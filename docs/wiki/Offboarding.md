# 离职办理与异常项结清

## 办理离职时的三种资产处理方式

| 方式 | 资产去向 |
| --- | --- |
| 回收 | 设备状态改为“闲置”；物资回补到所选仓库库存 |
| 转交 | 设备改挂到目标人员名下，分配关系重建 |
| 异常待处理 | 设备状态改为“丢失”；物资分配记为“已取消”且不回补库存 |

「异常待处理」用于“人已经离职、东西暂时说不清”的场景：允许先把离职办完，
但资产被明确标记为异常，后续必须有人跟进。

## 结清闭环

离职人员 → 查看详情 → 「异常项」表格，每项都能看到状态与处理信息：

1. **去处理**：跳到办公终端（自动带设备名搜索）或物资管理，把资产状态改成实际结果；
2. **结清**：选择处理方式（已找回 / 已报废 / 已赔付 / 其他）并填写备注，记录处理人与时间；
3. **撤销结清**：误点可恢复为“待结清”，操作记录保留（`audit_log` 可查）。

列表上的标签：

- 有未结清项 → 红色「待结清 N/总数」；
- 全部结清 → 灰色「异常已结清 N」；
- 没有异常项 → 「—」。

归档快照不可修改，结清状态单独存在 `left_employee_exception` 表，互不影响。
