# 网络拓扑

页面：`/topology`。连线关系由**端口连接**决定，画布上的设备由你**手动摆放**。

## 画布怎么用（v3.0.24）

* **设备默认不在画布上**：右侧「设备池」列出当前筛选（机房 / 机柜 / 只看有链路）下还没上画布的
  设备池；点一台设备再点画布空白处，就把它放到那个位置；也可以点「全部放入画布」按端口连接
  一次性分层铺开；
* **移出画布**：选中设备后点右侧「移出画布」，它只从画布上拿走（坐标删除），设备与链路不受影响；
* **保存**：摆放完点「保存布局」（可保存节点坐标与"移出画布"的删除），下次打开按保存值还原；
* **缩放与平移**：工具栏有 `− / 百分比 / ＋ / 适应窗口 / 100%` 五个控件，滚轮以光标为中心缩放，
  **空格 + 左键**（或中键）拖动平移，画布默认 1:1，设备多时不会被整体缩小到看不清；
* **节点大小**：紧凑 / 标准 / 放大三档；缩放太小时自动先隐藏型号文字、再隐藏设备名，悬停仍有完整提示；
* **机柜分组框**：同一机柜的设备用虚线框圈起来并标注机柜名，可开关；
* **搜索定位**：顶栏搜索设备名/型号/机柜，点「定位」会选中它并居中；如果它不在画布上，会先放到当前视野中心；
* **悬停顺线**：鼠标停在某台设备上时，与之无关的节点与链路淡出；
* **文字批注**：点工具栏的**文字图标按钮**（悬停显示「加文字」）→ 点画布位置 → 输入文字，
  即可在图上写说明（拖动改位置，右侧面板可改正文 / 标题 / 警示样式或删除）。

## 在图上直接编辑（v3.0.15）

选中设备后就能加端口、连链路，不用再切到设备面板：

1. 点顶栏「新建链路」，按提示**点 A 端设备 → 选端口（或新建端口）→ 点 B 端设备 → 选端口（或新建端口）**，
   再填介质、长度与标签即可建立链路；
2. 选中设备后，右侧「端口管理」可以看端口状态与对端：绿色「空闲」的才能连线，已连接的端口会显示对端设备与端口；
3. 设备一个端口都没有时，端口弹窗里有三个入口——**按型号生成**（用型号库模板，或直接复制另一台已配好端口的设备）、
   **批量生成**（例如按 `GE1/0/{n}` 一次生成 1–24 口）、**手工添加**（逐条填，除名称外都可以留空）；
4. 点画布上的连线可以改**介质 / 长度 / 标签 / 状态 / 备注**，也能删除这条链路。

除了上面这种点选式连线，还有两种更快的操作（v3.0.16 起）：

* **拖拽连线**：节点右边缘有一个小圆点（连线手柄），按住它拖到另一台设备上松手，
  弹窗里确认两端的端口即可（会自动预选两边第一条空闲端口）；
* **框选多台设备**：在空白处按住拖动拉出一个框，框内的设备会被一起选中，
  拖动其中任意一台就能整组平移。

拖动过的布局可以**撤销 / 重做**：工具栏的「撤销」「重做」按钮，或快捷键 `Ctrl+Z` / `Ctrl+Y`
（最多回退 50 步）。撤销只针对节点位置；端口和链路的增删请用端口弹窗与「链路属性」。

画布上同一对设备之间的多条链路（堆叠 / LACP）会**并排显示**，不会叠成一条；
连线颜色按介质区分，可在「正交走线 / 直线走线」之间切换，链路标签可以整体开关。
拖动节点支持网格吸附，「只看选中设备相关」会只留下选中设备与它直接相连的设备。

> 规则：一个端口同时只能有一条链路；两端不能是同一台设备；端口/链路变更都会写审计。

## 自动分层

以连接度数最高的节点为根（通常是核心交换机或防火墙）做 BFS 分层，
层级依次为「边界 / 核心 → 汇聚 → 接入 → 末端」，同层按机柜与名称排序。

「全部放入画布」与「重新布局」都会用这套分层规则排布**已经在画布上的设备**；
坐标保存在表 `topology_node_position`（每台设备一行，删掉就是"移出画布"）；
顶栏在存在未保存拖动时提示「有未保存的拖动」，按钮变为「丢弃未保存」。

画布上的文字批注存在表 `topology_annotation`，接口为
`POST /api/rack-layout/topology/annotations`、`PUT .../annotations/{id}`、
`POST .../annotations/{id}/remove`；删除是软删除（`is_active = 0`），留审计。

## 筛选与展示

* 按机房、机柜过滤；「只看有链路的设备」可隐藏孤立节点；
* 链路标签可开关，标签为空时显示介质；
* 点击节点查看型号、所在机柜与 U 位、端口占用与链路清单；
* 悬停或选中节点时，与它相连的链路会高亮。
* 筛选条件、走线方式、节点大小、机柜分组框与缩放比例会**记住上次的选择**（存在浏览器本地）。

## 导出

* 导出 SVG（矢量，适合贴进变更单）；
* 导出 PNG（前端 `SVG → Image → Canvas → toBlob`，不需要服务端渲染）；
* 导出**链路清单** CSV（A/B 端设备与端口、介质、长度、标签、状态、备注），适合交给布线/施工；
* 导出**节点清单** CSV（设备、型号、类别、机房、机柜、起始 U 位、端口数、已连端口、层级）；
* 打印视图。

导出的 SVG 使用固定颜色，不依赖页面主题，便于放进文档。

## 数据来源

节点来自机房设备台账 + 机柜位置（`rack_device_placement`），
边来自链路（`rack_cable_run`）。因此要让拓扑准确，先把端口连对；
后续阶段可以引入 SNMP/LLDP 自动发现，产出「待确认链路」由人工确认后再入库。
