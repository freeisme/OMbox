# 巡检中心（机房 / 弱电间 / 会议室 / 机柜）

页面：`/inspection`（导航分组「巡检管理」，标题「巡检中心」）。
巡检对象**包含机房、弱电间、会议室和它们下面的机柜**，不包含办公区终端与 IT 物资仓库。

## 会议室模块（v3.0.18）

侧边栏「巡检管理 → 会议室」（`/meeting-rooms`）是会议室与会议室内设备的独立维护页：

* 新增 / 编辑 / 删除**会议室**（名称、位置、备注，编码可留空自动生成），会议室是独立对象，不挂机柜；
* 列表直接显示每个会议室的**设备数**，点「设备（N）」打开设备清单与登记表单；
* 每个会议室可以登记**会议室内设备**：从 IT 物资分配（选仓库 + 型号，按数量扣库存，
  移除时原路退回）或自定义登记（只记录，不动库存）；
* 系统自带「会议室巡检」模板（33 项，类别含环境、显示设备、连接功能、音频设备、视频设备、
  视频会议、网络、供电、控制设备、辅助设备、线缆与安全、其他），可以直接用，也可以自己改；
* 巡检仍在「巡检中心」发起，开始巡检时可以**多选对象**：每个对象生成一张巡检表，属于同一个批次。

## 模板维护（v3.0.18）

模板可以新增、**编辑**、**删除**，并选择适用对象（机房 / 弱电间 / 会议室 / 通用）：

* 编辑：改编码、名称、适用对象、说明，检查项可增删改、调整顺序；
* 删除：会二次确认；历史巡检表保留当时的模板名称与检查项快照，不受影响；
* 开始巡检时只能勾选与模板适用对象匹配的对象（例如会议室模板只能选会议室）。

## 流程

1. **开始巡检**：选择模板与对象（机房 / 弱电间 / 会议室 / 机柜，**可多选**），执行人默认是当前账号；
2. 开始后按模板**快照**出本次的全部巡检事项；
3. **逐项记录**：正常 / 异常 / 不适用，可填实测值与说明；
4. **异常必须填说明**，填写与提交两个环节都会校验；
5. 全部事项检查完才能**提交**，提交后任务与明细只读，不能修改也不能作废；
6. 输出**巡检表**：整页预览、下载巡检表（CSV，带事项明细）、**导出本次巡检表**
   （同批次的多个对象横向排列：一行一个检查项、一列一个对象，末列汇总异常说明），打印视图。

作废未提交的任务必须填写原因，并写入审计。

## 任务操作（v3.0.18）

巡检任务列表的「操作」是一列下拉菜单：

| 菜单项 | 什么时候出现 | 说明 |
| --- | --- | --- |
| 查看 | 总是 | 打开巡检表，逐项查看/填写结论 |
| 下载巡检表 | 总是 | 导出这一张任务的 CSV（含检查项、结论、检查人与时间） |
| 导出本次巡检表 | 该任务属于某个批次时 | 同批次多个对象横向排列：一行一个检查项、一列一个对象 |
| 作废 | 任务「进行中」且有修改权限 | 必须填原因；已提交的巡检表不能作废 |
| 删除（已作废） | 任务「已作废」且有删除权限 | 删除任务与它的检查项明细（会二次确认并写审计） |

作废只是标记状态、保留记录；确认这条记录不需要了再删除。

### 按模板上传表格导入巡检表

现场已经在纸质表格或别的系统里做完巡检时，可以「下载模板」后按表头填好再「导入巡检表」：

1. 表头固定为：**巡检对象**、机柜、检查项分类、检查项、检查方法、结论、实测值、说明；
2. 「巡检对象」写机房 / 弱电间 / 会议室**名称**（必须已存在）；机柜可选，填了就必须属于该对象；
   一份表格只能对应一个对象（或一个机柜）。旧表头「机房」仍可导入；
3. 结论写「正常 / 异常 / 不适用」；异常项必须写说明，否则该行会被跳过；
4. 支持 `.xlsx`、`.xlsm`、`.csv`（UTF-8 或 GBK），一次最多 1000 行；
5. 导入成功后生成一份**已提交**的巡检记录，执行人是导入人；被跳过的行会按行号逐条列出原因。

### 为什么填了还提示未检查

系统判定“已检查”的唯一依据是**该行选了结论**（正常 / 异常 / 不适用）。
只在输入框里写实测值或说明不算已检查——这也是它最容易踩的坑，尤其模板里的
「本次巡检发现的问题与处理建议」是文本型事项，很多人直接在框里写字但没点结论。

为避免这种情况，执行页现在：

* 数值 / 文本 / 选项型事项多一个「保存」按钮，点它按当前结论（没选就按正常）保存该行，
  在输入框里按回车也等价；
* 保存单项只刷新这一行和顶部统计，不会把其它行还没保存的输入冲掉；
* 输入内容实时暂存，切换页面或重新加载任务后会带回来；
* 点「提交巡检表」时，如果有"填了内容但没选结论"的行，会按事项名称提示你；
* 顶部统计直接显示「未检查」条数，提交报错也会列出具体是哪几项。

## 巡检模板

模板包含若干巡检事项，每项记：类别、事项、检查方法、取值类型（正常异常 / 数值 / 文本 / 选项）、
单位、正常范围、是否必填。

系统自带两张标准模板：机房巡检（16 项）与弱电间巡检（14 项）。
修改模板只影响**之后开始**的巡检，历史巡检表保留当时的快照。

## 扫码开检（可选）

打开形如 `/#inspection?rack=<机柜编码>` 的链接会自动进入巡检页并预选该机柜，
配合机柜上的二维码即可扫码开检；编码不存在时不弹窗。

## 权限与审计

权限模块 `inspection_management`（查看 / 创建 / 修改 / 删除 / 导出）。
审计动作覆盖：机房与机柜维护、模板维护、开始巡检、提交巡检、作废巡检。
